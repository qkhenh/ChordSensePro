\textbf{ChordSense Pro} --- An AI-Powered Context-Aware System for Musician's Interactive Practice Workspace with Harmonic Analysis Support

\section{Background and Motivation}

For musicians who play guitar, piano, or any chordal instrument, one of the most fundamental skills is understanding the \textbf{harmonic structure} of a song --- which chords are used, how they function within the musical key, and how they relate to each other. This knowledge is essential for learning songs by ear, improvising, and composing original music.

Currently available tools on the market leave a significant gap:

\begin{itemize}
    \item \textbf{Chord recognition tools} (e.g., ChordAI, Chordify) can automatically identify chords from a song, but they stop there. They provide raw chord labels (e.g., ``Am7'', ``G9'') with no deeper musical context --- no analysis of harmonic function, no scale suggestions, and no interactive practice features.
    \item \textbf{Sheet music players} (e.g., Song Master Pro) offer looping and playback control, but lack intelligent harmonic analysis and cannot recognize complex extended chords (9th, 11th, 13th) reliably.
    \item Neither category allows musicians to \textbf{edit, annotate, and save} their own version of a chord chart with personalized voicings or corrections.
\end{itemize}

The core insight of this project is that \textbf{chord recognition is only the raw data layer}. The real value lies in \textbf{translating that raw data into musical knowledge} and providing a \textbf{closed-loop practice environment} where musicians can analyze, study, and drill any song they want.

\section{Project Objectives}

\textbf{ChordSense Pro} is a full-stack web application combining an AI-powered chord detection engine with a client-side harmonic analysis engine and an interactive practice workspace.

\subsection{AI-Powered Chord Detection (DE/AI)}

The system accepts a song input (YouTube URL or uploaded audio file) and produces a time-stamped chord event timeline. Key contributions:

\begin{itemize}
    \item \textbf{Source separation:} Isolate the harmonic instrument track from drums, bass, and vocals using Demucs before analysis.
    \item \textbf{Extended chord recognition:} Using a fine-tuned deep learning model (\textbf{MERT-v1-330M} + LoRA, Cascaded 3-Head architecture), the system reliably recognizes complex chords including 9th, 11th, 13th, diminished, and augmented extensions --- which current commercial tools (ChordAI, Chordify) handle poorly. The model is trained on Google Colab Pro (A100 GPU) for maximum accuracy on extended chords.
    \item \textbf{Beat-aligned output:} Chord events are synchronized to the beat grid (BPM, time signature, offset) enabling pixel-accurate display on the visual grid.
    \item \textbf{Real-time detection:} Sub-500ms latency for live microphone input during practice sessions.
\end{itemize}

\subsection{Sheet Generation Engine (DE/AI + FE)}

A key differentiator of ChordSense Pro is its ability to generate musical notation directly from audio --- bridging the gap between raw chord detection and practical musician output. The system supports two modes based on the input type:

\begin{itemize}
    \item \textbf{Mode A --- Vocal Music $\rightarrow$ ChordPro Format:} For songs with lyrics, the system runs Whisper ASR on the separated vocal track to extract word-level timestamps, then aligns detected chord change events to lyric word boundaries, producing a standard ChordPro sheet:
    \begin{quote}
        \texttt{Em l\`{a} [F]ai t\`{u} \dj{}âu b\uhorn{}ó\'{c} [G]\dj{}\'{e}n n\ohorn{}i \dj{}ây di\d{u} [Am]d\`{a}ng chân ph\uhorn{}\ohorn{}ng}
    \end{quote}
    Export formats: \texttt{.chordpro}, \texttt{.txt}, \texttt{.pdf}.

    \item \textbf{Mode B --- Instrumental Music $\rightarrow$ Lead Sheet:} For instrumental tracks (guitar solo, piano, synth lead), the separated melody track is processed by \textbf{CREPE} (pitch tracking) or \textbf{Basic Pitch} (Spotify, polyphonic transcription) to extract note events with onset/duration. Notes are quantized to the beat grid and rendered as a standard lead sheet using \textbf{VexFlow} in the browser. Export formats: \texttt{.mid}, \texttt{.musicxml}, \texttt{.pdf}.
\end{itemize}

\subsection{Harmonic Analysis and Interactive Workspace (BE/FE)}

Built on the client side to eliminate network latency, the Harmonic Engine provides:

\begin{itemize}
    \item \textbf{Roman Numeral Analysis:} Each chord is automatically labeled with its harmonic function (I, ii, V7, etc.) within the song's detected key, helping musicians understand why a progression sounds the way it does.
    \item \textbf{Scale Mapping:} Each chord is mapped to its corresponding improvisation scale (Ionian, Mixolydian, Dorian, etc.), providing instant guidance for soloists.
    \item \textbf{Smart Grid View:} A synchronized, beat-aligned chord grid that highlights the current chord in real time, with click-to-seek (accuracy $<$100ms) and A/B looping for drilling specific sections.
    \item \textbf{Practice Tools:} Web Audio API metronome and playback speed control (0.5x, 0.75x) without pitch distortion.
    \item \textbf{Edit Marker and Personal Library:} Musicians can override AI-detected chords with their own interpretation and save personalized chord charts to a cloud playlist.
    \item \textbf{Chord Dictionary:} An interactive encyclopedia with guitar fretboard and piano keyboard diagrams, with in-browser audio synthesis.
\end{itemize}

\section{Practical Significance}

\begin{itemize}
    \item \textbf{For self-taught musicians:} Enables anyone to learn the harmonic structure of any song in minutes, without formal theory training or expensive lessons.
    \item \textbf{For advanced musicians and composers:} Deep harmonic context (Roman numerals, scale mapping) accelerates understanding of complex jazz and contemporary progressions.
    \item \textbf{Sheet generation:} Uniquely among student-level tools, ChordSense Pro generates musician-ready output --- ChordPro sheets for vocal music and lead sheets (with melody transcription) for instrumental tracks --- exporting to standard formats (\texttt{.chordpro}, \texttt{.mid}, \texttt{.musicxml}, \texttt{.pdf}).
    \item \textbf{Scientific contribution:} The project proposes a Cascaded 3-Head LoRA architecture for extended chord recognition that outperforms current commercial tools, and publishes an open Vietnamese piano chord dataset for the research community.
\end{itemize}
