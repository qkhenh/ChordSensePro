\section{Context \& Background}

\begin{itemize}
    \item \textbf{Digital Music Learning Trends.}
    Modern instrumentalists --- guitarists, pianists, bassists, and songwriters --- increasingly rely on digital media (YouTube videos, streaming tracks, local audio files) for self-study, transcribing, and practice routines.

    \item \textbf{Rise of Automatic Chord Recognition (ACR).}
    Advances in Machine Learning and Digital Signal Processing (DSP) have enabled automatic chord transcription platforms such as ChordAI, Chordify, and Song Master Pro, making chord detection accessible to a wide audience.

    \item \textbf{The Industry Gap.}
    Traditional ACR solutions treat chord label detection as the final deliverable. However, for a practicing musician, raw chord symbols are simply \textbf{unprocessed data}. True musicianship requires understanding the \textbf{harmonic function} of each chord (Roman numerals, scale relationships) and having access to a \textbf{structured, interactive practice environment} --- neither of which existing tools provide.
\end{itemize}

% =============================================
% SECTION 3: PROBLEM STATEMENT
% =============================================
\section{Problem Statement}

Current ACR solutions create significant friction for musicians across three key dimensions:

\begin{enumerate}

    \item \textbf{Lack of Harmonic and Contextual Insight.}
    Most platforms only output isolated chord labels (e.g., \texttt{C}, \texttt{G}, \texttt{Am}, \texttt{Em}) with no analysis of their function within the song's key.
    \begin{itemize}
        \item They lack \textbf{Roman Numeral Analysis} (e.g., I -- V -- vi -- IV), making it impossible for players to grasp progression logic, understand chord relationships, or transpose across keys with confidence.
        \item No \textbf{Scale Mapping} is provided, leaving musicians without guidance when attempting to improvise solos, construct vocal harmonies, or compose fills.
    \end{itemize}

    \item \textbf{Fragmented Practice Workflow.}
    Musicians are forced to juggle multiple disconnected applications simultaneously: a media player for audio playback, a separate app for chord charts, a standalone metronome for timing, and a fingering reference tool.
    \begin{itemize}
        \item Crucial practice capabilities --- such as millisecond-precision click-to-seek, A/B looping for difficult passages, and pitch-preserving tempo shifting --- are either absent or poorly implemented.
    \end{itemize}

    \item \textbf{Rigidity and High Latency.}
    AI chord detection is inherently imperfect, yet most web-based tools offer no mechanism for users to override erroneous detections or substitute alternative voicings.
    \begin{itemize}
        \item Switching between simplified (\emph{Basic}) and extended (\emph{Precise}) chord representations typically requires a server round-trip, introducing sluggish response times and disrupting the user's practice flow.
    \end{itemize}

\end{enumerate}

% =============================================
% SECTION 4: THE SOLUTION — CHORDSENSE PRO
% =============================================
\section{The Solution: ChordSense Pro}

\textbf{ChordSense Pro} transforms raw AI chord detection into actionable musical intelligence within an \textbf{all-in-one, end-to-end interactive workspace}. The system is composed of four tightly integrated subsystems:

\subsection{Client-Side Harmonic Engine}

Implemented entirely in the browser to eliminate network latency:

\begin{itemize}
    \item \textbf{Roman Numeral Analysis:} Each detected chord is automatically labeled with its harmonic function relative to the song's detected key. For example, in C Major, \texttt{Dm} is dynamically annotated as \emph{ii} and \texttt{G7} as \emph{V7}.
    \item \textbf{Context-Aware Scale Mapping:} Each chord is mapped to its recommended improvisation scale (e.g., Ionian, Dorian, Mixolydian), providing instant, actionable guidance for soloing and lead playing.
    \item \textbf{Zero-Latency Mode Switching:} Toggling between \emph{Basic} (simplified) and \emph{Precise} (extended) chord representations is handled entirely client-side via a down-mapping algorithm --- no server communication required.
\end{itemize}

\subsection{Interactive Practice Workspace and Synchronized Player}

\begin{itemize}
    \item \textbf{Smart Bar-Based Grid View:} A beat-aligned chord grid rendered with sub-100ms synchronization accuracy using \texttt{requestAnimationFrame}, bypassing Virtual DOM overhead for real-time performance.
    \item \textbf{Click-to-Seek and A/B Looping:} Clicking any bar on the grid seeks audio playback to that bar's exact timestamp. Users drag-select a range of bars to create seamless A/B loops for targeted finger-technique drilling.
    \item \textbf{Dynamic Metronome and Pitch-Preserving Speed Shift:} A Web Audio API metronome generates accurate click pulses synchronized to the track's BPM. Playback speed can be scaled to $0.5\times$ or $0.75\times$ without pitch distortion.
\end{itemize}

\subsection{Ultimate Chord Dictionary with Built-In Synthesizer}

\begin{itemize}
    \item Interactive visual fingering diagrams for both \textbf{Guitar Fretboards} and \textbf{Piano Keyboards} are displayed for every chord on the grid.
    \item An in-browser \textbf{Soundfont Synthesizer} audibly renders voicing structures upon user click, enabling immediate ear training without any external tools.
\end{itemize}

\subsection{User Customization and Cloud Storage (UGC)}

\begin{itemize}
    \item An \textbf{Edit Marker} modal allows users to correct AI-detected chords, modify bass note voicings, or insert new chord events at any timestamp.
    \item The Harmonic Engine \textbf{automatically recalculates} Roman numerals and scale suggestions in real time whenever a user edit is made.
    \item All original AI analyses and user-customized charts are persisted in an \textbf{Event-Based Timeline schema} (PostgreSQL JSONB), enabling cloud-synced personal playlists with full edit history.
\end{itemize}

\section{Target Audience}

\begin{enumerate}

    \item \textbf{Gigging Musicians and Band Members.}
    Performing musicians who need to rapidly transcribe, internalize, and rehearse setlists directly from YouTube recordings or audio demos. The Roman Numeral Analysis layer enables immediate transposition to match a vocalist's key during live rehearsals or on stage.

    \item \textbf{Music Students and Self-Taught Learners.}
    Beginners and intermediate players seeking to progress beyond mechanical chord memorization toward genuine music theory comprehension. The A/B Loop and pitch-preserving speed-shift tools are particularly valuable for mastering fast chord transitions at a controlled tempo.

    \item \textbf{Music Producers, Songwriters, and Educators.}
    Music creators who analyze harmonic progressions in hit records to extract inspiration for new compositions. Educators can leverage the interactive Smart Grid and Scale Mapping as a dynamic visual teaching aid for music theory instruction.

\end{enumerate}
